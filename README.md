# Taller 2 Corte - Investigación sobre React

## Información general

- **Asignatura:** Desarrollo de Frontend
- **Actividad:** Taller 2 del segundo corte
- **Modalidad:** Individual
- **Fecha de entrega:** 16 de octubre de 2026

## Objetivo

Investigar y comprender los fundamentos de React resumiendolos con mis palabras segun lo investigado, su utilidad en el desarrollo de interfaces web, sus principales características y su importancia en la industria tecnológica.

## Contenido del taller

El documento desarrolla los siguientes temas:

1. **¿Qué es React?**  
   Definición, origen, clasificación como biblioteca y enfoque declarativo.

2. **¿Qué problema resuelve React?**  
   Manipulación del DOM, diferencias entre los enfoques imperativo y declarativo, estado y reutilización de componentes.

3. **Principales elementos de React**  
   - Componentes.
   - JSX.
   - Props.
   - Estado mediante `useState`.
   - Eventos como `onClick` y `onChange`.

4. **Importancia de React en la industria**  
   Ventajas, ecosistema de herramientas, comunidad y relevancia profesional.

5. **Empresas que utilizan React**  
   Ejemplos de empresas reconocidas como Meta y Airbnb.
